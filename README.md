🛒 Ecommerce Web Application

A full-stack Ecommerce web application developed using Spring Boot, JSP, Hibernate, and MySQL. It allows users to browse products, manage cart, and place orders, while admins can manage products and customer orders.

⚙️ Technologies Used

⭐ Java
⭐ Spring Boot
⭐ JSP
⭐ Hibernate / JPA
⭐ MySQL
⭐ HTML, CSS, Bootstrap
⭐ Maven

✨ Features

🔸 User Registration & Login
🔸 Product Listing & Search
🔸 Add to Cart / Remove from Cart
🔸 Checkout & Order Placement
🔸 Admin Dashboard (Manage Products & Orders)
